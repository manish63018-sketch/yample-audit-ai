# AuditAI

AuditAI is a modern AI-powered website auditing platform by Yample Labs that helps businesses identify performance, SEO, accessibility, security, and conversion issues. It generates professional reports, business insights, and actionable recommendations to improve user experience and drive growth.

Volumes:
- Volume 1–5: Core audit engine, AI Engine scaffolding
- Volume 6: Lead Intelligence Engine + CRM (scaffolded)
