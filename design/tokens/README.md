# Design Tokens

This folder contains canonical design tokens for AuditAI.

- `colors.json` — color palette and semantic tokens (dark & light modes).
- `typography.json` — font families, base sizes, line heights, and heading scale.

Usage

Convert these tokens into your chosen format (CSS variables, Tailwind config, or design tool tokens).

Example (CSS variables):

```
:root {
  --color-primary: #2563EB;
  --color-background: #F8FAFC;
  --font-body: Inter, ui-sans-serif, system-ui;
}
```
