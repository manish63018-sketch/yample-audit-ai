# 05 — Frontend

## Pages & Routes
- Landing, Features, Pricing, Docs, About, Contact
- Auth: Login, Register, Forgot Password
- App: Dashboard, Audit, Report, History, Billing, Team, Settings, Admin

## Design System
- Apple × Stripe × Linear × Vercel aesthetics
- Dark Mode first, Glassmorphism subtle effects, motion with purpose
- Accessibility: WCAG 2.2 AA compliance

## Components & Patterns
- Reusable UI library (shadcn/ui + Tailwind)
- Server Components where appropriate
- Loading/empty/error states standardized

## Coding Rules
- TypeScript only, no placeholder code, proper error handling, SOLID and Clean Architecture
