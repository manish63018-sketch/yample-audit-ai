# 06 — Backend

## API & Services
- Next.js API routes for lightweight endpoints
- Background workers for heavy audit tasks

## Auth & RBAC
- Supabase Auth for authentication
- Role-based access: admin, client, developer, billing
- Policies via Postgres RLS

## Table of APIs
- /api/audits — create/list audits
- /api/reports — fetch generated reports
- /api/teams — team management

## Error Handling & Observability
- Structured errors, telemetry (Sentry), traceable logs, audit logs
