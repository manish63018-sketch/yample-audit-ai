# 08 — Audit Engine

## Automated Analyses
- Lighthouse, Google PageSpeed, Core Web Vitals (LCP, CLS, INP, TTFB)
- SEO checks, Accessibility (Axe), Security headers, SSL, robots/sitemap, broken links

## Business Metrics
- Conversion Score, UX Score, Revenue Opportunity, Mobile Experience, CTA Analysis

## Pipeline
- Crawl → Static analysis (HTML/CSS/JS) → 3rd-party metrics (PageSpeed) → AI summarization → Report
