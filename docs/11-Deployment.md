# 11 — Deployment & DevOps

## Infrastructure
- Vercel for frontend and serverless edge/API routes
- Supabase for DB and storage
- Cloudflare for CDN, DNS, WAF

## CI/CD
- GitHub Actions for tests and linting, deploy to Vercel on `main` or `release/*`

## Backups & DR
- Regular DB backups, storage snapshotting, disaster recovery runbooks
